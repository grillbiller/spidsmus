# Spidsmus 🕷️🐭

Spidsmus is a mobile game project built with JavaScript, CSS, and HTML.

## About the game

Spidsmus is a fast, fun mobile game where players react quickly, avoid danger, and chase high scores.  
The game is designed to be easy to pick up, with simple controls and short sessions that make it perfect for playing on the go.

## Features

- Mobile-friendly gameplay
- Simple and responsive controls
- Score-based progression
- Lightweight web tech stack (JavaScript, CSS, HTML)

## Tech stack

- **JavaScript** (game logic)
- **CSS** (styling and layout)
- **HTML** (structure)

## Getting started

1. Clone the repository:
   ```bash
   git clone https://github.com/grillbiller/spidsmus.git
   ```

2. Open the project folder:
   ```bash
   cd spidsmus
   ```

3. Run locally:
   - Open `index.html` directly in your browser, or
   - Use a local server (recommended), for example with VS Code Live Server.
